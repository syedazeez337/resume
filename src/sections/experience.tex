\ossproject
{CoreDNS (CNCF Graduated)}
{DNS server powering service discovery in every Kubernetes cluster}
{Jul 2025 -- Jan 2026}
{
\item Fixed SRV record case handling to comply with RFC 6763 for proper mDNS/DNS-SD
      service discovery (\href{https://github.com/coredns/coredns/pull/7402}{PR \#7402})
\item Corrected TXT record comparison logic per RFC 1035, merged into v1.12.3
      (\href{https://github.com/coredns/coredns/pull/7413}{PR \#7413})
\item Eliminated flaky multisocket tests via fresh port allocation and channel-based
      cleanup (\href{https://github.com/coredns/coredns/pull/7438}{PR \#7438})
\item Hardened ready, pprof, and health plugins against slowloris attacks by adding
      server timeouts per gosec G114 (\href{https://github.com/coredns/coredns/pull/7798}{PR \#7798})
\item Resolved integer overflow warnings across 26 files by adding bounded gosec G115
      suppressions (\href{https://github.com/coredns/coredns/pull/7799}{PR \#7799})
}
