\textbf{Projects I've Built}

\textbf{\href{https://github.com/syedazeez337/purple-ai-sandbox}{Purple AI Sandbox}} -- Secure runtime for untrusted AI agents in Rust. Multi-layer isolation using eBPF packet filtering, seccomp-BPF syscall validation, Linux namespaces, and cgroups v2 resource limits. Ships with pre-built security profiles, async REST API (Tokio/Axum), token auth, and structured JSON audit logging. Built this because I wanted AI agents that can execute code without compromising the host.

\textbf{\href{https://github.com/Brevetest/core}{breveTest}} -- Declarative API testing framework in Java. Define REST tests in \texttt{.breve} config files, zero test code required. Auto-discovers tests during Maven builds, supports all HTTP verbs, integrates into CI/CD pipelines.
